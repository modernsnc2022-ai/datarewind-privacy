1. 앱과 처리 범위

DataRewind은 사용자가 직접 연결하고 승인한 외장 저장장치의 복구 작업을 휴대폰에서 수행하는 Android 앱입니다.

  • USB 메모리
  • USB/OTG 외장 저장장치
  • 지원되는 USB/OTG 카드리더에 연결한 SD카드

현재 v4는 휴대폰 사진·동영상·오디오 라이브러리 전체 접근 권한을 요청하지 않으며, 휴대폰 내부 저장소에서 삭제된 사진·동영상 복구를 제공한다고 주장하지 않습니다. 휴대폰 내장 microSD 슬롯의 RAW 복구도 지원하지 않으며, SD카드는 USB/OTG 카드리더를 통해 연결해야 합니다.

2. 처리 목적

외장 저장장치의 파일시스템 확인, 읽기 전용 RAW/시그니처 검색, 복구 후보 미리보기·검색·필터, SHA-256 무결성 확인, 사용자가 요청한 복구 파일 내보내기에 사용합니다.

3. 서버 전송

현재 앱은 Android INTERNET 권한을 요청하지 않으며 복구 자료를 개발자 서버로 전송하지 않습니다. 광고 SDK, 분석 SDK, 앱 계정 기능이 없습니다.

4. 보관 및 삭제

복구 작업 중 후보 파일과 작업 정보가 앱 내부 저장소에 임시로 생성될 수 있습니다. 사용자가 내보낸 파일은 사용자가 선택한 위치에 남으며, 앱 내부 임시 자료는 앱의 정리 기능으로 삭제할 수 있습니다.

5. 원본 보호

지원되는 USB/SD 복구 경로는 원본을 읽기 전용으로 취급하며 소스 쓰기 SCSI 명령을 구현하지 않습니다. 복구 전 원본 저장장치에 새 데이터를 쓰거나 포맷하지 마세요.

6. PC 정밀 복구

SD카드, USB/OTG 메모리 또는 외장 HDD에서 DataRewind로 원하는 파일을 찾지 못한 경우 별도 PC용 Recovery Doctor의 정밀 복구 안내 페이지를 열 수 있습니다. 이 연결은 외장 저장장치용 상위 복구 단계이며 휴대폰 내부 삭제 데이터 복구를 약속하지 않습니다.

1. Scope

DataRewind is an Android app for user-initiated recovery work on external storage that the user physically connects and authorizes.

  • USB drives
  • USB/OTG external storage
  • SD cards connected through a supported USB/OTG card reader

The intended v4 build does not request broad access to the phone's photo, video, or audio libraries and does not claim recovery of deleted photos or videos from Android internal storage. RAW recovery from the built-in microSD slot of a phone is also not supported; connect the SD card through a USB/OTG card reader.

2. Purposes

External-media data is processed locally for file-system inspection, read-only RAW/signature scanning, preview/search/filtering, SHA-256 integrity checks, and user-requested export.

3. Transmission

The current app does not request Android INTERNET permission and does not upload recovery content to a developer server. It has no advertising SDK, analytics SDK, or app account system.

4. Retention

Recovery candidates and work information may be created temporarily in app-private storage. User-exported files remain at the destination chosen by the user. App-private temporary recovery material can be removed using the in-app cleanup function.

5. Source protection

Supported USB/SD recovery paths treat the source as read-only and do not implement source-write SCSI commands. Do not write new data to or format the source before recovery.

6. PC deep recovery

If DataRewind cannot find the wanted file on an SD card, USB/OTG device, or external HDD, the user may open the separate Recovery Doctor PC deep-recovery guidance. This escalation path is for external storage and does not promise recovery of deleted Android internal-storage data.
