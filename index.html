1. 앱과 처리 범위

DataRewind은 이용자가 직접 시작한 데이터 복구·단서 확인 작업을 휴대폰에서 수행하는 Android 앱입니다. Android에서 허용된 범위와 이용자가 명시적으로 승인한 데이터만 읽습니다.

  • 해당 접근 권한이 허용된 사진, 동영상, 오디오 및 Android 휴지통 원본
  • 이용자가 시스템 폴더 선택기로 직접 선택한 문서·다운로드 등 파일
  • 이용자가 연결하고 접근 권한을 승인한 USB/SD 외부 저장장치

앱은 Android가 접근을 허용하지 않는 내부 UFS/userdata의 영구 삭제 바이트를 직접 RAW 복구한다고 주장하지 않습니다.

2. 이용 목적 및 처리 방식

검사, 복구 단서 분류, 로컬 미리보기, SHA-256 무결성 검증·동일 바이트 비교, 이용자가 요청한 복구 파일 내보내기 또는 .rdcase 인계 파일 생성에 사용합니다. 일반적으로 접근 가능한 기존 파일은 삭제 원본의 복구 성과로 표시하지 않습니다. USB/SD 원본에는 RAW 소스 쓰기 SCSI 명령을 실행하지 않습니다. Android 휴지통 원본 복원은 이용자가 시스템 승인 화면에서 동의한 경우에만 실행합니다.

3. 서버 전송 및 제3자 제공

현재 앱은 Android INTERNET 권한을 요청하지 않으며 복구 자료를 개발자 서버로 전송하지 않습니다. 광고 SDK, 분석 추적 SDK, 앱 계정 기능이 없습니다. 이용자가 직접 Downloads 또는 시스템 파일 선택기에서 지정한 저장 위치에 내보낼 수 있으며, 클라우드 제공자를 선택한 경우 해당 제공자의 별도 처리방침이 적용될 수 있습니다.

4. 보관 및 삭제

복구 후보, 임시 인계 파일 및 작업 증거 로그는 앱 내부 저장소에 생성될 수 있습니다. 앱의 '앱 내부 임시 복구자료 삭제'를 이용하여 삭제할 수 있습니다. 원본 USB/SD, 원본 휴대폰 파일과 이미 외부로 내보낸 자료는 이 기능으로 삭제되지 않습니다. 임시 복구자료는 Android 클라우드 백업 및 기기간 전송에서 제외하도록 설정했습니다.

5. 권한 및 선택 범위

권한은 해당 기능을 이용자가 시작할 때 요청합니다. 거부하면 해당 검사 범위가 제한되지만 나머지 기능을 계속 이용할 수 있습니다. Android 14 이상에서 일부 사진·동영상만 승인된 경우 그 선택 범위만 검사하며 전체 라이브러리 검사로 표시하지 않습니다.

6. PC용 Recovery Doctor

모바일 검사에서 복구 단서를 확인하지 못한 경우 별도 PC용 Recovery Doctor의 Android 포렌식 사전 진단을 안내할 수 있습니다. PC 포렌식 엔진이 휴대폰 앱에서 작동하거나 자동으로 PC 사이트에 연결되는 기능은 현재 제공하지 않습니다. 일반 USB/ADB 연결만으로 암호화된 내부 영구 삭제 데이터 복구는 보장되지 않습니다.

1. Scope

DataRewind performs user-initiated Android recovery discovery locally. It accesses only data made available by Android or explicitly authorized by the user: permitted photos, videos and audio; user-selected folders via the system file picker; and user-connected, user-authorized USB/SD mass storage. It does not claim raw recovery of permanently deleted internal UFS/userdata inaccessible to the app.

2. Purposes

Authorized data is used on-device for recovery candidate scanning and classification, local preview, SHA-256 integrity verification and exact-byte correlation, user-requested export, or creation of a user-requested .rdcase handoff. Ordinary accessible files are not presented as recovered deleted originals. USB/SD RAW source-write SCSI commands are not implemented. Restoring an Android trash original requires system confirmation and user approval.

3. Transmission and sharing

The current app does not request the Android INTERNET permission and does not upload recovery content to a developer server. It has no advertising SDK, analytics tracking SDK, or app account system. The user may export to Downloads or a destination selected using Android's system picker; a cloud provider chosen by the user may process the exported file under its own policy.

4. Retention and deletion

App-private recovery candidates, temporary handoff files, and proof/session logs may be created during recovery. The in-app temporary-data cleanup removes these app-private materials, not original phone/USB/SD data or files already exported to a destination chosen by the user. App-private recovery evidence is excluded from Android cloud backup and device-to-device transfer rules.

5. Permissions

Permissions are requested when the user starts the relevant feature. Denial limits the corresponding scan but does not block other functions. On Android 14+, selected-photo/video access is treated as partial scope, not full-library access.

6. Separate PC application

After an authorized phone scan finds no recovery lead, DataRewind may show guidance for the separate PC Recovery Doctor Android forensic preflight. The PC forensic engine does not run inside the phone app, and automatic PC website navigation is not currently provided. Ordinary USB/ADB access cannot guarantee recovery of encrypted permanently deleted internal data.
