Recovery Doctor로 추가 검사

휴대폰에서 찾지 못한 파일을 PC에서 추가로 살펴보려면 아래 순서를 확인하세요.

공개 배포 준비 중

PC용 Recovery Doctor 설치 안내

현재 공식 Windows 설치 파일과 Microsoft Store 제품 링크가 공개되지 않았습니다. 준비되지 않은 프로그램의 설치나 자동 실행을 안내하지 않습니다.

공식 배포가 준비되면 이 페이지에서 검증된 설치 경로를 안내합니다. 비공식 설치 파일을 내려받지 마세요.

휴대폰과 PC 연결 순서

  1. USB 데이터 케이블로 Android 휴대폰을 Windows PC에 연결합니다.
  2. PC용 Recovery Doctor가 공식 배포된 후 PC에서 설치·실행합니다. USB를 연결했다고 PC 프로그램이 자동 설치되지는 않습니다.
  3. PC에서 연결 상태, 장치 읽기 가능 여부와 암호화 등 제약을 먼저 진단합니다.
  4. 휴대폰에서 요구하는 접근 승인을 직접 확인하고, 본인이 선택한 범위의 검사만 진행합니다.

원본 보호 안내

원본에 쓰기·초기화·루팅·부트로더 변경을 시도하지 마세요. USB/ADB 연결만으로 암호화된 내부 저장소의 삭제 데이터를 복구할 수 있다는 뜻은 아닙니다. 진단 및 복구 결과는 기기 상태와 실제 접근 권한에 따라 달라집니다.

이미 DataRewind에서 확인한 단서가 있다면 앱의 .rdcase 인계 기능을 이용할 수 있습니다. 이 파일은 휴대폰 내부 저장소의 원시 이미지가 아닙니다.
